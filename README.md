# GS ERP — DEO Daily Report

A mobile-friendly, Google Forms-style daily transaction counter for GS ERP Data Entry Operators.

## Use

Open `index.html` in a browser. Enter the DEO name, date, location, and shift, then tap an operation card and enter transaction counts. Counts accept whole numbers only. The summary totals entries across all operation tabs. Save a report to keep it in the browser, and use **Export CSV** to download saved reports for review.

## Included operation tabs

- Arrival Operations
- FTF Transfer (Send and Receive)
- Return to Factory
- Production
- Local Sales
- Export

## Storage

This starter version saves reports in the current browser's local storage. Reports are not shared between devices or users and are not sent to a central database. CSV export lets a supervisor consolidate submissions. A shared reporting inbox or database can be connected when its preferred service and access details are available.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will show the published URL on the Pages settings screen.
